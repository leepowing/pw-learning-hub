YEAR 8 SCIENCE CHAPTER 3 — PERIODIC TABLE OPTIMISATION

Purpose
-------
This overlay removes the requirement for a Year 8 student to memorise every
element shown on the supplied table. It retains the complete table as a
reference, limits direct symbol/name recall to 20 core elements, and changes
state, metal/non-metal and group-order tasks into reference-supported skills.

Main results
------------
- 98 focused flashcards instead of 152.
- 72 quiz questions instead of 82.
- 20 core element symbol/name recall points.
- The complete 74-element source table remains available and is displayed
  inside the five questions that require table lookup.
- Chapter Quiz and Cross-Chapter Quiz use the same reference-image behaviour.

Installation
------------
Copy this folder's contents into the project root, preserving paths. Review
the three shared files listed in SHARED-FILES-CHANGELOG-PERIODIC-TABLE.md before
overwriting a locally modified version.

Validation
----------
Follow PERIODIC-TABLE-UPDATE-INSTRUCTIONS.md. Automated validation, TypeScript,
targeted ESLint and the production build passed in the supplied project copy.

No git commit, push or deployment is included.
