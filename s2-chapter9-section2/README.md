# S2 Chapter 9 Section 9.2 — Isosceles Triangles

Requires the Chapter 9 homepage package and shared geometry component.
Extract this folder beside package.json, then run:

```
node s2-chapter9-section2/install.cjs
npm run build
```

Open /maths/s2/chapter-9/isosceles-triangles.

Includes equal base angles, the converse, equilateral triangles, the isosceles 60-degree result, a written proof and 8 numeric exercises. Proofs use Statement / Reference columns. Answers are temporary page state, not saved to Supabase.

The installer backs up and patches the homepage, preserves the 9.1 link, and refuses different existing lesson files. Keep package payloads as .txt.

Validated: isolated strict TypeScript and rendering, three new SVG diagrams visually inspected, installer and repeat installation. Full Next build and browser behaviour require checking locally.
