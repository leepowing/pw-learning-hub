# RPE revision quiz tests

Phase 1 contains one registered RPE chapter. The shared revision route therefore aggregates Chapter 1 only. Chapter 2 will be included automatically when it is later registered with subject `RPE`.

Checks:

- Registry query uses year 8 and subject `RPE` only.
- Only taught sections unlock questions.
- Multi-section questions require all referenced sections.
- MCQ options are randomised without changing the stored answer.
- Mixed mode can include MCQ, Short, Long and available interactive formats.
- Results are grouped by chapter and question type by the shared component.
- Storage remains separated by organiser, subject route and current student.
- No History, Science, English, Geography or Design Technology question is included.
