S2 Chapter 10 — Polygons: Homepage

1. Extract this ZIP into E:\Projects\pw-learning-hub.
2. Open a terminal in that project (beside package.json).
3. Run: node s2-chapter10-homepage/install.cjs
4. Run: npm run build
5. Open /maths/s2/chapter-10 on your running website.

Includes chapter overview, interactive polygon triangulation, textbook references,
regular polygon formulas, tessellation check and compass construction preview.
Sections 10.1–10.4, checkpoint and flashcards are marked coming soon.

Installs:
app/maths/s2/chapter-10/page.tsx
components/maths/S2Chapter10Geometry.tsx

The installer leaves identical files alone and stops if an existing file differs.
Optional preflight: node s2-chapter10-homepage/install.cjs --dry-run
No database changes or chapter-list changes are included.

Validation: isolated strict TypeScript check, server rendering and visual SVG
inspection. Run the full build in your project to verify integration.
