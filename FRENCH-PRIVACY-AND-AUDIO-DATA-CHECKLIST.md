# French Privacy and Audio Data Checklist

- Microphone access begins only after a learner action and browser consent.
- The interface explains that speech is sent to Azure for pronunciation assessment.
- Audio is streamed for assessment and is not written to the app database or package.
- The Azure key remains server-only; the browser receives only a short-lived token.
- No raw audio, transcript or pronunciation result is retained by this feature.
- Teachers should follow the school's privacy notice, safeguarding policy and Azure data-region requirements.
- If policy does not permit cloud speech processing, disable pronunciation assessment; flashcard listening and all non-speech revision remain available.
