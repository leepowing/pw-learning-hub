# Spanish Cross-Chapter Quiz Tests

- Route resolves and uses the Spanish organiser registry entry.
- Only taught sections contribute questions.
- Visible modes are Multiple Choice, Short Questions, Long Questions, Interactive Questions and Mixed Questions.
- Question and MCQ option randomisation use the existing Fisher–Yates implementation.
- Spanish character keys insert at the textarea cursor.
- Written answers are sent using organiser and trusted question IDs; client-supplied rubrics are not accepted.
- Final score, type breakdown and chapter breakdown use the returned marks.
- Pronunciation scores are not included in quiz or accuracy totals.

Status: passed by TypeScript, targeted ESLint and production build. Browser microphone behaviour still requires the normal manual device check after deployment.
