一 A、目前已發現的來源疑點——正式開發前必須核對

以下只屬疑點，不可未經批准直接改寫：

1. Page 2 有可見的編輯 comments／review balloons，例如對分類、`était comment?` word order 及希望增加 phrases 的備註。這些 comments 預設只進入 audit，不可當成學生要學的 source content；正式開發前須確認是否排除。
2. Page 2 item 29 `j’ai retrouvé mes amis` 的 English 印作 `I met my friends`。較精確可能是 `I met up with／saw my friends again`；須決定保留 printed meaning，還是採用 approved teaching meaning 並保留 diff。
3. Page 2 question `était comment?` 有原稿 comment 指 word order 可能需要改善。不可靜默改成 `Comment c’était ?`；須由使用者批准。
4. Page 3 Top 10 opinions item 8 印作 `c’est` = `I would like`；通常 `I would like` 對應 `j’aimerais`。
5. Page 3 Top 10 opinions item 9 印作 `c’était` = `I think that`；通常 `I think that` 對應 `je pense que`。
6. Page 3 Top 10 opinions item 10 印作 `ce sera` = `In my opinion`；通常 `In my opinion` 對應 `à mon avis`。
7. Page 3 Top 10 connectives item 9 印作 `où` = `then`；`où` 通常解作 `where`，`then` 通常可用 `puis／ensuite／alors`，須核對原意。
8. Page 3 Top 10 être／avoir item 10 印作 `je serai` = `I will have`；`je serai` 通常是 `I will be`，`I will have` 通常是 `j’aurai`。
9. Page 3 Top 10 time phrases item 10 `quand je serai grand.e` 的 English 印作 `when I’m bigger(f)`；較自然意思通常是 `when I am older／grown up`，且 `grand／grande` 的標示須核對。
10. Page 3 perfect tense item 6 `j’ai bu` 的 English 印作 `I(’ve) drank (drunk)`，混合 simple past 與 past participle；學生顯示形式須由使用者批准。
11. Page 3 的 shorthand，例如 `intéressant.e`、`ennuyeux(-euse)／barbant.e`、`amusant.e.s／drôle.s`、`marrant.e.s／rigolo.te.s`、`nouveau.x／nouvelle.s`、`vieux／vieille.s`，不可當作學生應輸入的完整 literal string。Learn 必須展開實際 forms，audit 保留原印刷表示法。
12. 所有疑點必須寫入 Wording／Correction Diff。可選處理只有：
   - 完全照印刷原文；或
   - 學生頁使用已批准的正確形式／meaning，同時保留 printed form、approved correction、批准日期和原因。

七、Quiz 題型、學生介面及出題規則

French Chapter Quiz 和 Cross-Chapter Quiz 顯示五個主類別：Multiple Choice、Short Questions、Long Questions、Interactive Questions、Mixed Questions。Matching、fill blanks、ordering、classification、translation 和 listening 集中於 Interactive Questions。

七 A、Multiple Choice

1. 測試 meaning、correct form、tense、auxiliary、agreement、connective、time phrase 和 phrase selection。
2. 每題四個 unique options，只有一個最佳答案。
3. distractors 使用合理錯誤，例如 subject、tense、auxiliary、article、gender、number、agreement、accent 或近義詞；不可使用荒謬選項。
4. 每次 session 使用 Fisher-Yates randomise questions 和 options。
5. answer／explanation 以 trusted source data 及 approved corrections 為準。

七 B、Short Questions

可包括 English → French、French → English、correct verb form、complete a sentence、explain connective／time phrase、change person／gender／number／tense、identify auxiliary。每個 required source item 至少由一條可追溯 Quiz question 明確覆蓋；不得只靠 Flashcard 代表 Quiz coverage。

七 C、Long Questions

1. 可要求寫一段簡短 French paragraph，例如：holiday location and transport；holiday activities；past holiday with opinions and weather；future holiday plans。
2. 題目只要求 KO 已教授或明確提供的語言。
3. rubric 可按 task content、required details、range、tense control、opinions／reasons／connectives、accuracy 分配。
4. 不可把篇幅本身當成主要分數；每分對應 trusted marking point。
5. 如要求多個 time frames，prompt 和 rubric 必須明確列出。

七 D、Interactive Questions

1. Matching：French ↔ English；phrase ↔ function；verb form ↔ subject／tense／auxiliary。
2. Fill in the Blanks：article、pronoun、auxiliary、past participle、agreement、connective、time phrase。
3. Ordering：把 words／chunks 排成正確 French sentence，保留 accents、apostrophes 和 punctuation。
4. Classification：past／present／future；opinion／connective／time phrase；`avoir`／`être`；positive／negative。
5. Translation builder：用 supplied chunks 組成完整 translation，保留正確 word order 及省音。
6. Listening：使用已核對的 French source phrase配合 `fr-FR` SpeechSynthesis；不可把自製語音當成老師原題。
7. Pronunciation Practice：trusted French target → Listen → Start recording → Stop and assess → feedback → Try again。
8. Pronunciation Practice 初期只作形成性練習，不計入任何 Quiz、accuracy、正式成績或排名。
9. 不需要 Label the Diagram，除非日後來源文件確實包含需標示的圖片。

七 E、Mixed Questions

1. 從已 taught sections 抽取合理比例的 MCQ、short、long 和 interactive。
2. 避免同一 source item 在同一 session 不必要重複。
3. 顯示總分、題型分布、section 表現和需要重溫的語言項目。

八、French AI 評分規則

1. Short／Long answers 由 server 根據 trusted question ID 重新取得 marking points；不可接受 client 傳入的 marks、answer 或 rubric 作權威資料。
2. API key 只留在 server environment；沿用 authentication、rate limit、input-length limit、timeout、error handling 和 fallback。
3. AI 按 vocabulary meaning、translation accuracy、omission／addition／opposite meaning、subject、tense、auxiliary、past participle、gender／number agreement、article、negation、word order、accent／cedilla／apostrophe、required detail 評分。
4. 一般 meaning question：小型拼字錯誤而 meaning 完全清楚時可接受，不可過度懲罰。
5. 明確 spelling／form／conjugation question：target form、ending、auxiliary、agreement、accent 和 apostrophe 屬 marking requirement。
6. accents／cedilla／ligature 不可一律忽略；是否扣分由 trusted rubric 和題目目的決定，feedback 必須指出問題。
7. 多個自然 translations 或 word orders 可按 meaning 接受，不要求與 model answer 逐字相同。
8. 不得要求 KO 未教授的外部 vocabulary 才能得滿分。
9. 每個 marking point 回傳 `Met`、`Partly Met` 或 `Not Met`；沿用現有計分時只有 `Met` 得 1 分，但 feedback 必須解釋改善方法。
10. wrong tense、wrong subject、wrong auxiliary、missing negation、contradiction 或 opposite meaning 不得因包含 keywords 而給分。
11. Long feedback 分為 What was done well、Corrections、How to improve、Improved model response。
12. Model response 只使用題目允許的 source language；新增語言標記 extension，不可當作 required answer。
13. AI summary、awarded marks、navigation 和 final results 必須一致；client 不可改寫 server score。

九、French 輸入、發音與可用性

1. Short／Long textbox 提供可選 French character buttons：`à â æ ç é è ê ë î ï ô œ ù û ü ÿ`，需要時另提供大寫形式。
2. 按鈕在 cursor 位置插入，不可清除答案；實體鍵盤、mobile keyboard、copy／paste 和 screen reader 均須可用。
3. Audio controls 有 accessible label，例如 `Play French pronunciation`。
4. SpeechSynthesis 優先 `fr-FR`；可配置其他 French locale 只作明確標示的 fallback。
5. 播放新內容前 cancel 舊 utterance；不可 autoplay。
6. 所有互動支援 keyboard、focus ring、correct／incorrect feedback 和 reduced-motion。

九 A、Azure Speech Pronunciation Assessment

1. 沿用已安裝的 Azure Speech SDK 及安全 server route；French recognition locale 預設 `fr-FR`，不可沿用 Spanish 的 `es-ES`。
2. 使用 scripted assessment：server 根據 trusted item／question ID 取得 `referenceText`；client 不可提供 reference text、expected answer、score 或 rubric 作權威資料。
3. `referenceText` 與頁面 target 及 model audio 一致；accents、apostrophes、approved display／source form 差異須有 audit。
4. 只顯示 Azure 對所用 French locale 實際回傳且官方支援的指標；不得把其他 locale 專用功能硬套到 French。上線前重新核對當時 Azure 官方文件及實測 response schema。
5. 流程：Listen → Start recording → Stop and assess → feedback → Try again。
6. Feedback 使用鼓勵語言，指出一至三個可改善 words／sounds；不可把合理口音差異描述成能力不足，也不可要求模仿單一 native accent。
7. `Good`、`Nearly there`、`Practise again` 門檻可配置，須以 Year 8 樣本校準，不可宣稱為官方等級。
8. 只在學生主動錄音時要求 microphone permission；拒絕／不支援時仍可 Listen and practise yourself。
9. 單字／短語錄音上限建議 15 秒，較長短句 30 秒；client／server 限制 duration、file size、MIME type、timeout、retry。
10. raw audio 預設只作即時評核，不永久儲存，不寫入 analytics、console、error log、database 或 object storage。
11. 可按 student 保存必要 metadata，例如 trusted item ID、attempt time、形成性分數及需練習項目；不可保存 raw audio 或跨學生顯示。
12. Azure credentials 只存 `AZURE_SPEECH_KEY`、`AZURE_SPEECH_REGION` 等 server environment variables；不得用 `NEXT_PUBLIC_`、送到 browser、提交 Git 或放入 ZIP。
13. assessment route 必須有 authentication、per-user rate limit、daily／monthly cap、payload validation、timeout、safe error 和 abuse protection。
14. 價格、免費額度、region availability 和 locale features 不可硬編碼；正式啟用前查核 Azure 官方最新資料。
15. app-side usage counter 達 warning threshold 時通知管理員，達 hard cap 時停止新 assessment；不能假設 budget alert 會自動停用服務。
16. Azure unavailable、timeout、quota exhausted 或 config missing 時安全降級，不可令 Learn、Flashcards 或 Quiz 失效。
17. 兒童使用前提供家長／監護人通知或同意流程，說明錄音用途、資料傳送、保存和刪除安排。
18. Pronunciation results 初期不影響 taught status、Flashcard accuracy、Quiz marks、Cross-Chapter totals 或排名。
