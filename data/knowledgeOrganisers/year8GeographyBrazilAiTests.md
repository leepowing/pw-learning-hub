# Brazil AI Marking Test Cases

Run these against the short- and long-answer marking route with the Geography organiser selected.

| Case | Student answer | Expected behaviour |
|---|---|---|
| Place accuracy | Names Rio de Janeiro when the question asks about Rio. | Credit only evidence relevant to Rio, not generic city claims. |
| Direction and scale | Gives a correct compass direction or distance from the supplied source. | Credit the relation only when direction, scale and place are accurate. |
| Figures and units | Uses a KO number with its correct unit. | Credit the figure; do not accept a mismatched unit. |
| Density vs distribution | Describes where people live but calls it density. | Identify the distinction and award only the supported point. |
| Urbanisation vs migration | Describes rural–urban migration as the movement and urbanisation as the growing urban proportion. | Credit both concepts when used correctly. |
| Push vs pull | Classifies lack of rural jobs as a push factor and urban employment as a pull factor. | Credit both classifications. |
| Process chain | Links a named deforestation cause to a stated consequence. | Credit each valid causal link up to the mark limit. |
| Unsupported fact | Adds a statistic not present in the KO or question source. | Do not treat it as required case-study evidence. |
| Equivalent wording | Uses a correct synonym rather than exact model wording. | Accept the meaning when geographically accurate. |
| Contradiction | Gives one correct fact and then contradicts it. | Do not award the contradicted marking point. |
