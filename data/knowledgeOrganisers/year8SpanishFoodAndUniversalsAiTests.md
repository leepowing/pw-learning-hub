# Spanish AI Marking Test Cases

1. Accept a natural equivalent translation when meaning and tense are correct.
2. Reject an answer using the opposite meaning, even when it repeats a keyword.
3. Reject the wrong person (`comí` for `comimos`) when person is a marking point.
4. Point out a missing accent for an exact-form question.
5. Treat `n` and `ñ` as different when the target word requires `ñ`.
6. Accept a minor spelling slip in a general meaning question when meaning is unambiguous.
7. Require stated opinion, reason, connective and time frame only when listed in the trusted marking points.
8. Keep the model response within taught KO language; label any extension.
