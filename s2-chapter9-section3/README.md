# S2 Chapter 9 Section 9.3 — Congruent Plane Figures

Requires the Chapter 9 homepage and shared geometry component.
Extract this folder beside package.json, then run:

```
node s2-chapter9-section3/install.cjs
npm run build
```

Open /maths/s2/chapter-9/congruent-plane-figures.

Includes translation/rotation/reflection views, correspondence tables, equal sides and angles, a worked example, a written task and 8 self-check questions. Answers are temporary page state, not saved to Supabase.

The installer backs up and patches the homepage, preserving 9.1 and 9.2. It refuses different existing lesson files. Keep payloads as .txt inside the package.

Validated: isolated strict TypeScript, React rendering, five SVG states visually inspected, installer and repeat installation. Run the full Next build and check browser interactions locally.
