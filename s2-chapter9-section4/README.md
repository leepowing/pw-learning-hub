# S2 Chapter 9 Section 9.4 — Similar Plane Figures

Requires the Chapter 9 homepage and shared geometry component.
Extract this folder beside package.json, then run:

```
node s2-chapter9-section4/install.cjs
npm run build
```

Open /maths/s2/chapter-9/similar-plane-figures.

Includes interactive scale factors and reflection, corresponding angles and sides, two worked examples, perimeter scaling, a written task and 8 numeric exercises. References use the textbook wording for corresponding parts of similar plane figures. Practice answers are temporary page state, not saved to Supabase.

The installer backs up and patches the homepage, preserving earlier lesson links. It refuses different existing lesson files. Keep payloads as .txt inside the package.

Validated: isolated strict TypeScript, React rendering, seven SVG states visually inspected, installer and repeat installation. Run the full Next build and check browser interactions locally.
